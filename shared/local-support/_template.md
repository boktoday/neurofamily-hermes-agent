# Local support: template for a new country or region

Copy this file, rename it to the country or region code (for example `nz.md`, `ie.md`, `ca-on.md`), and fill it in from official sources only.

## Rules for the agent when adding a region

1. Take every number and address from an official source (the organisation's own site or a government site). Never from memory.
2. Mark every entry with the date it was verified.
3. Keep the honest labels: which lines are 24/7 crisis services, which are information lines with office hours, which are charities run by volunteers.
4. Save the family's actual region in the profile so the right file loads every time.
5. If a country is missing, use **findahelpline.com** (a verified international directory) plus the family's GP or paediatrician as the bridge, and say plainly that the local list is still being built.

## Sections to fill

- **Crisis, right now** — emergency number, national crisis lines, youth line, carer or parent line.
- **Autism** — the national autism organisation and helpline.
- **ADHD** — the national ADHD organisation(s).
- **Broader support and systems** — disability support schemes, carer support, early childhood and school pathways.
- **Language help** — interpreter services, if they exist.
- **Country note** — anything state, province or region specific.
