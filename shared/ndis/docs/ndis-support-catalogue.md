What the support catalogue is

The support catalogue lists all available NDIS supports providers can use when requesting a payment.

What the support catalogue is for

The support catalogue gives information on what we consider to be an appropriate maximum price for each NDIS support item.  

It also shows which claim type applies to each support item.

It should be used in conjunction with the NDIS pricing schedule.

What the support catalogue is like

The support catalogue includes:

registration group numbers
names
support category numbers and names  
if a quote is required
claim period  
appropriate maximum prices  
remote and very remote areas.  

The catalogue also lists guidance for claiming:  

non-face-to-face support
travel
irregular supported independent living (SIL) supports.  

It includes information about cancelling appointments with participants at short notice and request reports.
