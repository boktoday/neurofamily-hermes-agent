# Daily routine anchors

**Skill:** routine-architect
**Default:** weekday mornings 7:00, family's timezone.
**Purpose:** one small, warm nudge that anchors the morning routine the family built, without nagging or adding load.

## The prompt

> Load the routine-architect skill. It is morning. Read the family folder (family-profile.md, child-summary.md, shared-notes.md). Write a short morning message (under 60 words): name today's shape in one line (school day or not), give one anchor from the current morning routine, and one tiny encouragement. If the family built a visual schedule artifact, mention it by name. Never add extra tasks. If the parent's capacity noted in the profile is low this week, cut the message to a single kind line.

## Notes

- If the family prefers, this doubles as the message that quotes the day's first-then card.
- Pause during school holidays if the routine changes; resume when asked.
