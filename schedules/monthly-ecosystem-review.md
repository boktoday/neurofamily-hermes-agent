# Monthly ecosystem review

**Skill:** family-navigator
**Default:** first Sunday 19:00.
**Purpose:** step back across the whole team: what helped, what is stuck, what changes.

## The prompt

> Load the family-navigator skill. Run the monthly ecosystem review. Read every file in the family folder plus recent shared notes. Write a short review (under 250 words): (1) what improved this month, specifically, (2) what is stuck or worsening, honestly, (3) which skills were used most and whether that mix still matches the current priorities, (4) one proposed change to the setup (a schedule to add or pause, a specialist to involve, a professional to loop in), (5) a one-line summary for the family's records. Ask the family to confirm or adjust, then update agent-coordination.md and active-concerns.md. If a professional referral is overdue on any open concern, say so plainly.

## Notes

- This is the moment to retire settled concerns and to re-read the profile against how life has actually changed.
- If the third month in a row shows the same stuck item, say plainly that it needs a human professional, not more support work.
