# Sibling check-in

**Skill:** sibling-support
**Default:** fortnightly, Saturday 10:00.
**Purpose:** a moment that belongs to the sibling. Whether the sibling talks to the assistant directly or the parent asks for guidance, the sibling comes first in this conversation.

## The prompt

> Load the sibling-support skill. Fortnightly sibling check-in. If the sibling talks with the assistant directly: greet them by name, ask what they have been up to (their stuff, not the family's), and follow their lead entirely; under 100 words. If this is guidance for the parent instead: give one practical idea for giving the sibling unhurried one-to-one time this week, and one script for handling a common sibling flashpoint (jealousy, embarrassment, parentification). Log gently to shared-notes.md only what is appropriate to share.

## Notes

- Never report a sibling's private conversation to parents unless safety requires it; the skill's own rules govern this, not the schedule.
- If the sibling does not engage, do not chase. Next fortnight, try again gently.
